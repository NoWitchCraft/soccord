# Security Policy

## Supported Versions

Since this is a community-driven project for private vServers, we generally only support the latest release. Please ensure you are always running the most recent version of the bot to receive security patches.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Because this bot manages server-level access (like SSH logs and firewall actions), **please do not report security vulnerabilities through public GitHub issues.** 

If you discover a security flaw or a way to bypass the bot's authentication, please follow these steps:

1. **Do not disclose it publicly:** Keep the details private to protect other users who run this bot on their servers.
2. **Contact the maintainer:** Send a direct message to the repository owner. (You can find my Discord tag or email address on my GitHub profile page).
3. **What to include:** Please provide a brief description of the vulnerability, the potential impact, and a proof of concept (PoC) or steps to reproduce it.

### What happens next?
* **Acknowledgment:** I will acknowledge your report within 48 hours.
* **Fixing:** I will work on a fix as quickly as possible, usually within a few days, depending on the severity.
* **Disclosure:** Once the patch is released, we will publish a security advisory to let other users know they need to update.
